## APIs

### News API

Locate articles and breaking news headlines from news sources and blogs across the web with our JSON API.

**Human URL:** [https://newsapi.org/](https://newsapi.org/)

**Base URL:** `https://newsapi.org/v2`

#### Endpoints

- `GET /everything` — Search through millions of articles from 150,000+ sources.
- `GET /top-headlines` — Live top and breaking headlines by country, category, or source.
- `GET /top-headlines/sources` — Available news sources and publishers.
